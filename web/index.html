Share from WhatsApp

Android easiest

  1. Install this app: browser menu ⋮ → Install app.
  2. In WhatsApp, long-press the voice note → Share → Interpreter.
  3. It opens here and translates on its own.

iPhone

  1. Long-press the voice note → Forward → tap Share (bottom-right) → Save to Files.
  2. Back here, tap Choose file → Browse → pick it.
  3. To install: Safari Share → Add to Home Screen.

WhatsApp Web

  1. Hover the voice note → ⌄ → Download, then choose it here.

No conversion needed: .opus, .ogg, .m4a, .mp3, .wav and .aac all work.
