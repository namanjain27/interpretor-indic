How do I get a voice note out of WhatsApp?

Android (easiest)

  1. Install this app: browser menu ⋮ → Install app / Add to Home screen.
  2. In WhatsApp, long-press the voice note → Share → pick Interpreter.
  3. It opens here and translates automatically.

iPhone

  1. Long-press the voice note → Forward → tap the Share icon (bottom-right) → Save to Files.
  2. Come back here → Choose voice note → Browse → pick the saved file.
  3. To install: Safari Share button → Add to Home Screen.

WhatsApp Web / Desktop

Hover the voice note → ⌄ → Download, then choose it here.

No conversion needed: WhatsApp's .opus/.ogg, plus .m4a, .mp3, .wav and .aac all work. Someone talking in front of you? Tap Record.
